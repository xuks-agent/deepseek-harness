# 一页验证表 · 外贸工厂 AI 询盘助手

> 编号：OPC-20261118-01 ｜ 提出人：GitHub #5 ｜ 日期：2026-11-18

## 1. 一句话定义
- 给 **谁**（ICP：行业/规模/角色）：中小外贸工厂（约 10–100 人、自有出口业务）的外贸业务员 / 老板，询盘回复靠人工、客户信息散落各处
- 解决 **什么痛点**：询盘（询价）回复慢、质量参差导致丢单；客户画像靠业务员经验记忆，难以沉淀复用
- 交付 **什么产物**：按月订阅的 AI 工具——接入询盘后自动生成回复草稿，并汇总客户画像（来源、需求、历史往来）
- 收 **多少钱**（一口价或按月）：3000 元/月（按月订阅）

## 3. 否决清单（任一命中即停）

- [ ] 目标客户说不清是谁（ICP 方向已定，但需访谈核实是否确为真需求）
- [ ] 需要垫资或先交付后付款
- [ ] 毛利预估 < 20%（取决于询盘量对应的 LLM 调用成本，待实测）
- [ ] 依赖平台规则且随时可能被封（若自动回复需接入 WhatsApp / 阿里国际站等平台，存在封号风险，待确认接入方式）
- [ ] 需要资质/牌照/资金门槛
- [ ] 同类竞品已价格战（需竞品调研确认）

## 4. 成本与毛利预估

- 预计工时（小时）：待估（MVP 搭建 + 每客户接入与维护）
- 预计成本（含获客）：未知；粗估单客户 LLM 调用成本约 100–500 元/月（按每月数百封询盘），获客成本未测
- 报价：3000 元/月
- 预估毛利 = 报价 − 成本：待成本实测后计算
- 预估毛利率 = 毛利 / 报价：无法确定（成本未知）
