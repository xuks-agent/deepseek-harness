# OPC 一人公司 · 运行目录

这个目录是「一人公司」闭环的**唯一事实来源**，所有环节都往这里写，不再散落在对话里。

| 文件 | 作用 |
| --- | --- |
| `项目台账.csv` | 每个项目的全生命周期：验证信号、获客成本、工时、报价、毛利、状态 |
| `验证表模板.md` | 立项前必须填的一页验证表（三硬信号 + 否决清单） |
| `validation/<slug>.md` | 每个项目的验证表实例 |

## 五步闭环与判据

1. **① 搜集项目** → 线索进入飞书「OPC 工作台」群，变成工单
2. **② 可行性验证** → 必须产出 `validation/<slug>.md`，且**三个硬信号齐全**才算通过：
   - ≥3 个真实用户访谈（有原话/日期）
   - ≥1 个竞品价格（有链接/截图）
   - ≥1 个付费意愿（愿意付多少钱、什么时候）
3. **③ 部门开工** → 只有②通过（台账状态 `已验证`）才允许开工
4. **④ 营销** → 1 个 ICP + 1 个平台，7 天 20 帖 / 50 私信；线索率 <5% 就停
5. **⑤ 交付收款** → agent 只做跟进与台账更新；**合同、收款、发票、退款永远人来做**

## 台账状态机

`待验证` → `已验证` → `试单` → `交付中` → `已回款`
任一步可转 `已放弃`；毛利为负的品类进黑名单。

## 红线

- 不做没有付费意愿的项目（避免"AI 们互相点头"）
- 不接毛利 < 20% 的活
- 不代签合同、不代收款、不开发票、不承诺退款
